## 1. 产品概述

### 1.1 产品定位

**PromptX** 是一款专为 AI 开发者、研究人员及重度大模型用户设计的轻量级桌面端提示词管理工具。以"键盘优先"、"极速唤醒"和"动态变量注入"为核心，解决高频、高度重复的 Prompt 输入痛点，保持心流不断线。

### 1.2 核心价值主张

| 价值维度 | 具体描述 |
|---------|---------|
| **极致性能** | 唤醒延迟 < 50ms，内存占用 < 50MB，安装包 < 10MB |
| **键盘优先** | 全程键盘操作，无需鼠标，肌肉记忆级交互体验 |
| **隐私安全** | 本地化存储，数据不上云，用户完全掌控 |
| **零摩擦切换** | 无边框悬浮窗，即用即走，不打断工作流 |
| **动态智能** | 变量自动填充，剪贴板智能读取，上下文无缝衔接 |

### 1.3 目标用户画像

| 用户类型 | 使用场景 | 核心诉求 |
|---------|---------|---------|
| **AI 应用开发者** | 频繁测试不同提示词效果，调试 Agent 行为 | 快速切换、版本管理、变量注入 |
| **大模型研究人员** | 进行提示工程实验，收集最佳实践 | 标签分类、模板复用、批量测试 |
| **内容创作者** | 使用 AI 辅助写作、翻译、润色 | 常用模板、一键上屏、跨应用使用 |
| **运维工程师** | 生成运维脚本、故障排查 Prompt | 结构化输出、剪贴板联动 |

### 1.4 竞品分析

| 产品 | 优势 | 劣势 | PromptX 差异化 |
|------|------|------|---------------|
| **系统剪贴板** | 系统原生、无额外安装 | 无分类、无搜索、无变量 | 分类管理 + 模糊搜索 + 变量注入 |
| **Notion/Obsidian** | 功能强大、多平台 | 启动慢、非专用、需要上下文切换 | 极速唤醒 + 键盘优先 + 专注提示词 |
| **Raycast/Alfred** | 扩展生态丰富 | 付费、剪贴板功能有限、非提示词专用 | 垂直场景 + 动态变量 + 深度定制 |
| **ChatGPT Custom Instructions** | 与 ChatGPT 深度集成 | 仅限 OpenAI 平台、功能单一 | 跨平台使用 + 本地管理 + 模板库 |

## 2. 市场背景与用户分析

### 2.1 市场背景

随着大语言模型（LLM）的广泛应用，AI 从业者和普通用户越来越依赖精心设计的提示词（Prompt）来获得高质量输出。然而，现有的解决方案存在以下痛点：

1. **重复输入效率低下**：相同或相似的提示词需要反复手动输入
2. **管理混乱**：提示词散落在不同工具（笔记软件、代码文件、聊天记录）中
3. **上下文切换成本高**：打开其他工具管理提示词会打断工作流
4. **缺乏动态能力**：无法根据当前上下文（如剪贴板内容）自动调整提示词

### 2.2 用户痛点矩阵

| 痛点 | 严重程度 | 发生频率 | PromptX 解决方案 |
|------|---------|---------|-----------------|
| 手动输入重复提示词 | 高 | 每日多次 | 一键上屏、快捷搜索 |
| 提示词版本混乱 | 中 | 每周多次 | 命名空间分类、标签系统 |
| 跨应用使用不便 | 高 | 每日多次 | 全局悬浮窗、系统剪贴板集成 |
| 无法动态调整内容 | 中 | 每周多次 | 变量注入、剪贴板自动读取 |
| 数据隐私担忧 | 中 | 持续关注 | 本地存储、不上云 |

## 3. 核心功能需求

### 3.1 功能概览

### 3.2 功能详细说明

#### 3.2.1 全局极速交互 (P0 - 核心功能)

**功能描述**: 用户可通过全局快捷键在任何应用中快速唤醒 PromptX 主界面。

| 子功能 | 详细说明 | 验收标准 |
|-------|---------|---------|
| **全局快捷键** | 支持自定义组合键，默认 `Alt + Space` (Windows/Linux) 或 `Option + Space` (macOS) | 1. 应用未运行时快捷键无效<br>2. 应用后台运行时可正常唤醒<br>3. 支持在设置中自定义修改<br>4. 与系统快捷键冲突时提示用户 |
| **无边框悬浮窗** | UI 呈现为居中的类 Spotlight 搜索框，位于屏幕中央偏上位置 | 1. 窗口置顶显示<br>2. 窗口透明度可调 (默认 95%)<br>3. 窗口大小自适应内容<br>4. 支持鼠标拖拽调整位置 |
| **极速响应** | 从按下快捷键到界面完全渲染的时间 | 1. 唤醒延迟 < 50ms (P95)<br>2. 首屏渲染 < 100ms<br>3. 内存占用 < 50MB<br>4. CPU 占用 < 1% (空闲时) |

**异常处理**:
- 快捷键冲突：显示友好提示，引导用户修改设置
- 多显示器支持：在当前活动显示器中央显示
- 全屏应用兼容：在游戏或全屏视频中的行为（可配置是否允许唤醒）

#### 3.2.2 键盘优先的检索与输出 (P0 - 核心功能)

**功能描述**: 提供高效的键盘导航和搜索体验，无需鼠标即可完成所有操作。

| 子功能 | 详细说明 | 验收标准 |
|-------|---------|---------|
| **模糊检索** | 基于拼音首字母、英文片段的智能匹配 | 1. 输入 `dj` 可匹配"代码重构"<br>2. 输入 `ref` 可匹配"Code Refactoring"<br>3. 搜索延迟 < 50ms<br>4. 高亮显示匹配部分 |
| **快捷导航** | 键盘方向键和功能键快速操作 | 1. `↑` `↓` 切换搜索结果<br>2. `Tab` 切换命名空间 (Spaces)<br>3. `Shift + Tab` 反向切换<br>4. `Esc` 关闭窗口<br>5. `Enter` 选中并输出 |
| **一键上屏** | 将选中提示词输出到当前光标位置 | 1. 窗口自动隐藏<br>2. 文本插入到光标位置<br>3. 支持撤销操作<br>4. 输出失败时提示用户 |

**搜索算法**:
```
搜索优先级:
1. 标题完全匹配 (权重: 100)
2. 标题前缀匹配 (权重: 80)
3. 标题包含匹配 (权重: 60)
4. 内容包含匹配 (权重: 40)
5. 标签匹配 (权重: 30)
6. 拼音首字母匹配 (权重: 20)
```

**键盘快捷键一览**:

| 快捷键 | 功能 | 备注 |
|-------|------|------|
| `Alt/Option + Space` | 全局唤醒/隐藏 | 可自定义 |
| `↑` `↓` | 上下切换结果 | - |
| `Tab` | 切换命名空间 | 循环切换 |
| `Shift + Tab` | 反向切换命名空间 | - |
| `Enter` | 选中并输出 | - |
| `Esc` | 关闭窗口 | - |
| `Ctrl/Cmd + N` | 新建提示词 | - |
| `Ctrl/Cmd + E` | 编辑选中项 | - |
| `Ctrl/Cmd + D` | 删除选中项 | 需二次确认 |
| `Ctrl/Cmd + ,` | 打开设置 | - |

#### 3.2.3 动态变量注入 (P0 - 核心功能)

**功能描述**: 支持在提示词中定义变量，在输出时自动替换为实际值。

| 变量类型 | 语法 | 说明 | 示例 |
|---------|------|------|------|
| **剪贴板** | `{{clipboard}}` | 自动读取系统剪贴板内容 | `解释以下代码：{{clipboard}}` |
| **日期** | `{{date}}` | 当前日期 (YYYY-MM-DD) | `今天是 {{date}}` |
| **时间** | `{{time}}` | 当前时间 (HH:mm:ss) | `当前时间：{{time}}` |
| **时间戳** | `{{timestamp}}` | Unix 时间戳 | `时间戳：{{timestamp}}` |
| **自定义** | `{{变量名}}` | 运行时弹窗填入 | `翻译为{{目标语言}}` |

**变量替换流程**:

```
┌─────────────────────────────────────────────────────────────┐
│                      变量替换流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. 用户选中包含变量的提示词                                    │
│              ↓                                               │
│  2. 解析提示词，识别所有 {{变量名}} 模式                        │
│              ↓                                               │
│  3. 检查变量类型：                                             │
│     ├── 系统变量 (clipboard, date, time, timestamp)          │
│     │   └── 自动获取值                                         │
│     └── 自定义变量                                             │
│         └── 弹出输入表单                                       │
│              ↓                                               │
│  4. 替换所有变量为实际值                                       │
│              ↓                                               │
│  5. 组装完整文本并输出                                         │
└─────────────────────────────────────────────────────────────┘
```

**剪贴板变量特殊处理**:
- 自动检测剪贴板内容类型（文本、图片、文件路径）
- 文本内容：直接替换
- 图片：提示用户无法处理或转换为描述文本
- 文件路径：读取文件内容或提示用户
- 超长文本 (>5000字符)：截断并提示用户

#### 3.2.4 双维数据管理 (P1 - 重要功能)

**功能描述**: 通过命名空间(Spaces)和标签(Tags)两个维度组织提示词。

**命名空间 (Spaces)**:
- 顶部分类标签页，用于横向分类
- 支持新建、重命名、删除、排序
- 默认创建三个空间：`默认`、`工作`、`个人`
- 每个空间可设置图标和颜色标识

**数据存储结构**:

**导入导出功能**:
- 支持导出为 JSON 格式
- 支持从 JSON 文件导入
- 导入时处理 ID 冲突（自动重命名或跳过）
- 支持增量导入（合并而非覆盖）

## 5. 交互与UI规范

### 5.1 设计原则

1. **极简主义**: 主界面仅保留必要元素，减少视觉干扰
2. **键盘优先**: 所有操作均可通过键盘完成，鼠标为辅助
3. **即时反馈**: 每个操作都有明确的视觉或动效反馈
4. **无障碍**: 支持高对比度模式、屏幕阅读器

| 窗口显示 | 淡入 + 轻微上移 | 150ms | `ease-out` |
| 窗口隐藏 | 淡出 | 100ms | `ease-in` |
| 结果选中 | 背景色过渡 | 100ms | `ease` |
| 标签切换 | 滑动过渡 | 200ms | `ease-in-out` |
| 输入反馈 | 边框颜色 | 150ms | `ease` |

## 7. 数据模型设计

### 7.1 核心实体模型

#### Prompt (提示词)

```typescript
interface Prompt {
  id: string;                    // UUID
  title: string;                 // 标题
  content: string;               // 内容 (支持变量语法)
  tags: string[];                // 标签列表
  spaceId: string;               // 所属空间 ID
  variables: Variable[];         // 解析出的变量列表
  usageCount: number;            // 使用次数
  lastUsedAt: string | null;     // 最后使用时间 (ISO 8601)
  createdAt: string;             // 创建时间 (ISO 8601)
  updatedAt: string;             // 更新时间 (ISO 8601)
}

interface Variable {
  name: string;                  // 变量名 (不含 {{ }})
  type: 'system' | 'custom';     // 系统变量 | 自定义变量
  defaultValue?: string;         // 默认值 (可选)
}
```

#### Space (命名空间)

```typescript
interface Space {
  id: string;                    // UUID
  name: string;                   // 空间名称
  icon: string;                   // 图标名称
  color: string;                  // 颜色 (HEX)
  order: number;                  // 排序序号
  promptCount: number;            // 提示词数量 (计算字段)
  createdAt: string;             // 创建时间
  updatedAt: string;             // 更新时间
}
```

#### Settings (设置)

```typescript
interface Settings {
  globalHotkey: string;           // 全局快捷键
  theme: 'light' | 'dark' | 'system';  // 主题
  language: string;               // 语言代码
  windowOpacity: number;         // 窗口透明度 (0-1)
  windowPosition: Position | null; // 窗口位置 (null = 居中)
  windowSize: Size;               // 窗口尺寸
  searchDebounce: number;         // 搜索防抖 (ms)
  maxResults: number;             // 最大结果显示数
  autoHide: boolean;              // 失去焦点自动隐藏
  showInDock: boolean;            // 是否显示在 Dock/任务栏
  launchAtLogin: boolean;         // 开机自启动
}

interface Position {
  x: number;
  y: number;
}

interface Size {
  width: number;
  height: number;
}
```
